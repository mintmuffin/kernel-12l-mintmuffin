# kernel-12l-mintmuffin

Clean Android 12L (ArrowOS 12.1 / AOSP) Exynos 9810 Kernel with AMOLED Green Screen Fix & KernelSU for Samsung Galaxy S9 / S9+ / Note9.

### Features:
- **Base Tree**: ArrowOS 12.0 / 12.1 (ArrowOS-Devices/android_kernel_samsung_universal9810)
- **Branding**: -mintmuffin-mafushii
- **AMOLED Green Screen Recovery**: Native ALPM hardware reset + forced 2-nit sequence for degraded DDIC displays
- **Rooting**: KernelSU built-in (CONFIG_KSU=y)
- **Clocks & Power**: Factory stock DVFS tables and thermal governors (smooth, cool, zero stutter)
